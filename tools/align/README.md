# Центровка подписей — замер по пикселям

Автотест и инструменты, чтобы подписи в кнопках, вкладках и плашках стояли ровно
посередине по вертикали, а значки — на одной высоте с заглавными буквами.
Меряем не по CSS, а по готовой картинке: безоконный Chrome снимает страницу,
и по пикселям находится «чернила» первой заглавной буквы и значка.

## Быстро

```bash
bash tools/align/check.sh                 # всё: панель, библиотека, welcome, окна на YouTube (~3 мин)
bash tools/align/check.sh yt-clip welcome # только эти страницы
bash check-syntax.sh --align              # синтаксис + центровка
```

Падает, если подпись дальше ±0,6 px от середины элемента (внутри рамки) или значок
дальше ±0,6 px от заглавной на экранах 150% и 200%. Переменные: `ALIGN_DPRS`
(`1,1.25,1.5,2` — все масштабы), `ALIGN_TH` (порог), `ALIGN_PORT` (8777),
`ALIGN_ALL=1` (печатать все отклонения), `ALIGN_JSON=итог.json`, `ALIGN_OUT=папка` (сохранить
снимки и рамки, а не удалять; путь — абсолютный).

На GitHub тест гоняется заданием «Центровка» (`.github/workflows/checks.yml`) на Windows —
там есть Segoe UI Variable. Если на раннере шрифта не окажется, задание предупредит и не
будет валить проверку. При отклонениях снимки и итог — в артефактах прогона.

Нужны: node 22+, python с Pillow и numpy, Chrome, сеть (окна на YouTube рисуются
шрифтом Roboto с Google Fonts — как на самом YouTube).

## Как устроено

| Файл | Что делает |
| --- | --- |
| `serve.py` | сервер стендов: корень репозитория с той же политикой скриптов, что у расширения; на лету подменяет `library/library.html` (заглушка `chrome.*`), `sidepanel/stand.html` (вся разметка панели сразу) и `/watch` (макет YouTube) |
| `pages.mjs` | список страниц: адрес, ширина, чего ждать, что открыть (окно, выбор карточек) |
| `shot.mjs` | безоконный Chrome со своим временным профилем: открывает страницы, вызывает `audit.js`, сохраняет снимок и рамки |
| `audit.js` | `__textAudit()` — для кнопок, вкладок, плашек: рамка элемента, толщина рамки сверху/снизу, первая заглавная, значок сбоку |
| `pixan.py` | по снимку: центр заглавной относительно середины «лица» элемента и центр значка относительно заглавной |
| `check.py` | итог и белый список `allow.txt` |
| `try.sh` | примерить CSS, не меняя файлы (добавляется на страницу и в тени окон) |
| `opt.py` | перебор величины сдвига `{k}` в шаблоне CSS |
| `stands/` | заглушки: библиотека с вымышленным каталогом, макет YouTube (превью, клип, плейлисты, меню, плашки; с `&ctx=1` — карточки справа и описание с таймкодами для своего меню правого клика, `&light=1` — светлая тема), колонка очереди |

## Подбор правки

```bash
python tools/align/serve.py 8777 &
ALIGN_DPRS=1,1.25,1.5,2 bash tools/align/try.sh my.css "t-btn|key" lib-triage
python tools/align/opt.py lib-triage "t-btn" ".t-btn > span{position:relative;top:{k}px}" 0 -1 -2
```

Что выяснилось при подборе:

- **Сдвиги — целыми пикселями.** Chrome округляет `top` у значков и отступы до целых
  css px: `top: -0.5px` даёт то же, что `0` или `-1px`.
- **Высоты в rem — через `round(…, 1px)`.** Корневой кегль библиотеки и welcome плавает
  с шириной окна, кнопка встаёт на полпикселя, и подпись «прыгает» на разных масштабах.
- **Асимметричный отступ двигает и значок.** Если значок уже по центру, а подпись нет —
  симметричный отступ и `position: relative; top` у подписи.
- **Segoe UI Variable** (панель, библиотека): заглавные ниже середины строки.
  **Roboto** (окна на YouTube): наоборот, выше — подписи опускаем.
- 150% — самый капризный масштаб: 1 пиксель экрана = 0,67 css px.

## Белый список

`allow.txt`: `регулярка :: причина :: допуск`. С допуском элемент всё равно падает,
если отклонение больше — исключение не прячет новую кривизну. Многострочные
элементы не сравниваются вовсе.
