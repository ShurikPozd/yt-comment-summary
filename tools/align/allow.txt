; Белый список центровки (tools/align/check.py): сознательные исключения.
; Строка: регулярное выражение « :: » причина [« :: » допуск в px].
; Выражение ищется в строке «<страница> <элемент> «<подпись>»», например:
;   welcome kbd.key «Shift»
; С допуском элемент всё равно падает, если отклонение больше допуска — так
; исключение не прячет новую кривизну. Без допуска — любое отклонение.
; Многострочные элементы (подпись или содержимое в две строки и больше) не
; сравниваются вовсе — для них строки не нужны.

; ---- не кнопки: середину рамки не с чем сравнивать
 a\.title « :: заголовок-ссылка карточки видео: не кнопка, рамка — сама строка текста
 label\.sort :: подпись «Порядок» у выпадающего списка: плашка — сам список, подпись стоит по строке
 summary\.q-h « :: заголовок раскрывающегося блока «Как работает очередь»: не кнопка, под ним отступ и линия

; ---- клавиши-плашки: центр по «лицу» над толстой нижней рамкой (так и меряется);
; строки клавиш стоят на дробных координатах (кегль страницы плавает с шириной окна),
; поэтому подпись в разных строках сдвигается на пиксель экрана — в среднем по центру
^(welcome|welcome-wide|panel|lib-triage) kbd :: клавиша-плашка на дробной координате строки :: 0.8

; ---- выверено главной сессией по сумме отклонений на 100/125/150/200% (блоки «Центровка
; подписей» в sidepanel.css и library.css); на 150/200% остаётся до 1 пикселя экрана.
; Подгонка под 150/200% уводит 100/125% — оставлено как есть, допуск не даёт стать хуже.
^lib\S* button\.chip :: чипы библиотеки — выверены по сумме 100–200%; мелкие (26px), место в карточках меняется от прогона к прогону — разброс до пикселя экрана :: 1.0
^lib\S* button\.pl « :: строки плейлистов — выверены по сумме 100–200% (значок в плашке слева) :: 1.0
^lib\S* button#(sem|subs)-btn :: «По смыслу» — выверено по сумме 100–200% :: 0.7
^lib\S* button\.ghost :: кнопки .ghost библиотеки — выверены по сумме 100–200% :: 0.8
^lib\S* button « :: переключатели длины и разделов — выверены по сумме 100–200% :: 0.8
^panel button#btn-shortcuts :: широкая .ghost в панели — выверена по сумме 100–200% :: 0.75

; ---- приветственная страница: кнопки «Открыть …» на 150% ниже середины на 1 пиксель
; экрана (2/3 css px); сдвиг на полпикселя Chrome округляет до целого и уводит 200%
^welcome\S* button\S*\.try « :: кнопка «Попробовать» на дробной координате карточки :: 0.8

^queue button «Назад» :: на 150% кнопка на дробной координате: 1 px экрана = 0,67 css px, ближе чем +0,74 не встаёт (на 100/125/200% — до 0,41) :: 0.8
