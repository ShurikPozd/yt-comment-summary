# Сквозной тест в Chrome

```
bash tools/e2e/run.sh          # или: node tools/e2e/run.mjs
```

Около 10 секунд. Нужны Node 22+ и Chrome: по умолчанию берётся стандартный путь
(Windows — `C:/Program Files/Google/Chrome/Application/chrome.exe`, Linux — `/usr/bin/google-chrome`),
другой путь задаёт переменная `CHROME`.

## Как это устроено

- **Chrome** запускается безоконным, с временным профилем, по пайпу CDP
  (`--remote-debugging-pipe --enable-unsafe-extension-debugging`). Расширение ставится командой
  `Extensions.loadUnpacked`: брендовый Chrome с версии 137 не понимает `--load-extension`.
- **Сети нет.** Все вкладки и фон расширения идут через перехват `Fetch.requestPaused`, ответы даёт
  `site.mjs`. Адреса настоящие (`https://www.youtube.com/watch?v=…`), поэтому контент-скрипты из
  `manifest.json` срабатывают так же, как на сайте. Всё, что не подменено, не уходит наружу:
  `--host-resolver-rules` не разрешает ни одного имени. Живой YouTube тест не открывает, капч нет.
- **Страницы** — снимки настоящей разметки YouTube (`fixtures/watch-flexy.html`,
  `fixtures/home-browse.html`), обезличенные: тексты заменены на «Текст N», id видео, каналов и
  плейлистов — вымышленные, без картинок, стилей и скриптов. Чего на снимке нет (сам плеер,
  `ytcfg`), делает `player.js`: ставит в `<video>` тишину нужной длины, даёт методы API плеера и, как
  YouTube, после F5 откатывает видео на 20 секунд назад.
- **Ответы youtubei** — `fixtures/next-video.json` (токен секции комментариев) и
  `fixtures/next-comments.json` (6 комментариев в нынешнем формате: `commentViewModel` +
  `frameworkUpdates`).
- **Бот сводок и Groq** — заглушка: тест проверяет, что запрос к `/api/chat` ушёл и в нём собранные
  комментарии. Секрет вымышленный, `local-config.js` не нужен.

## Что проверяется

1. Расширение загрузилось, фон запустился.
2. Кнопка расширения в плеере появилась; меню открывается и закрывается по Esc.
3. Все модули плеера встали; «Поиск по речи»: `Ctrl+Shift+F` → «собака» находит «Собаки» и
   «собаку» (субтитры — подменённый ответ `youtubei/v1/get_panel`), `↓` + `Enter` перематывает.
4. Комментарии собираются через youtubei и правильно разбираются (автор, лайки, сердечко).
5. Кнопки на обложках рекомендаций (`video-actions.js`) и кружок выбора (`select.js`) — на `/watch`.
6. «В очередь»: выбор карточки → полоса «Выбрано» → «В очередь» → видео в `storage.local.queue`.
7. «С того же места после обновления» (`resume.js`): 123 с → F5 → YouTube откатывает на 103 с →
   расширение возвращает 123 с.
8. Кнопки на обложках главной (обычные карточки и полка Shorts).
9. Боковая панель (отдельным окном): «Анализировать» отправляет комментарии боту.

Плюс: исключения в коде расширения на страницах тоже валят тест.

## Переменные

- `E2E_OUT=папка` — при сбое сохранить снимок экрана вкладки (в CI уходит в артефакты).
- `E2E_HEADFUL=1` — с окном, посмотреть глазами.
- `E2E_EXT=папка` — проверить другую копию расширения (например, нарочно сломанную — убедиться,
  что тест ловит поломку).

## YouTube поменял вёрстку

Тест на снимке не узнает об этом сам — снимок нужно переснять:

1. В обычном Chrome открыть видео YouTube и главную (лучше без входа в аккаунт или помнить, что
   рекомендации личные — обезличивание всё равно заменит тексты и id).
2. DevTools → Console → вставить `tools/e2e/snap.js` целиком: обезличенная разметка окажется в
   буфере обмена.
3. Вставить в `fixtures/watch-flexy.html` или `fixtures/home-browse.html`, просмотреть `git diff`,
   запустить тест. Упал — значит, расширение не справится и на живом YouTube: чинить расширение.
